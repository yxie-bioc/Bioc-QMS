实例与更新

更新：完整解压新版本到另一个目录，保留旧运行包，双击新包的“启动网站”。系统先停止旧服务，再备份并独立恢复核对，最后执行迁移。数据目录不随程序覆盖。

迁移失败时网站不会继续启动。请用升级前版本，将其备份恢复为新实例；仅换回旧程序不等于数据库回退。

本机与内网共享

同事只需网址与各自账号。数据库不对内网开放；管理入口始终只在本机。

HTTP 模式仅供合成数据试验。HTTPS 需要 IT 配置主机名、证书和客户端信任；不要忽略证书警告。防火墙规则必须由 IT 明确批准，仅开放所选网站端口和公司子网。

本工具不会安装系统服务、自动启动项、防火墙规则或根证书。网络地址变化时重新选择当前地址；固定 IP 或内部 DNS 请由 IT 配置。
